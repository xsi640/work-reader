# Work Reader

一个 **长得像 ChatGPT** 的本地小说阅读器。左侧是会话式书库，右侧以对话消息的形式逐章展开正文，输入框既是阅读指令，也是全文搜索框。

所有书库、进度、书签都在浏览器本地（IndexedDB + localStorage），不需要服务端。

## 功能

- **ChatGPT 同款界面**：260px 侧边栏、48rem 阅读栏、`#f9f9f9 / #ffffff` 浅色与 `#171717 / #212121` 深色主题、28px 圆角输入框、会话分组（今天 / 昨天 / 过去 7 天 / 更早）。
- **导入 TXT**：拖拽文件到窗口，或点击侧边栏 / 输入框的 `+`。自动识别 `第一章`、`第 1 回`、`序章`、`楔子`、`Chapter 1` 等标题；没有标题时按长度自动分段。
- **对话式阅读**：章节以助手消息流式展开；用户指令以气泡出现。
- **全文搜索**：`⌘K` / `Ctrl K` 搜索书名、章节与正文，命中处高亮，点击直接跳章。
- **阅读设置**：字号、行距、衬线 / 无衬线、页宽、浅色 / 深色 / 跟随系统。
- **阅读辅助**：书签、章节进度、目录、朗读（浏览器 SpeechSynthesis）、复制本章、随机读一章。
- **本地优先**：刷新、重开浏览器后进度与书签仍在；可删除单本或清空全部数据。

## 开始

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 产物在 dist/
npm run preview
```

## 输入框指令

| 输入 | 行为 |
| --- | --- |
| `下一章` / `继续` | 读下一章 |
| `上一章` | 读上一章 |
| `第 3 章` / `第三章` / `3` | 跳到指定章 |
| `目录` | 在消息中展开目录 |
| `书签` | 为当前章添加 / 移除书签 |
| `从头开始` | 回到第一章 |
| `搜索 灯塔` / `搜索：灯塔` | 全文搜索 |
| 直接输入一句话 | 在全书里搜索这句话 |

未打开书时，直接输入书名（支持《书名》）即可打开。

## 快捷键

| 快捷键 | 行为 |
| --- | --- |
| `⌘K` / `Ctrl K` | 搜索书库与正文 |
| `Alt` + `←` / `→` | 上一章 / 下一章 |
| `Enter` | 发送 |
| `Shift` + `Enter` | 换行 |
| `Esc` | 关闭弹层 |

## TXT 分章规则

优先按行首标题切分：

```
第一章 潮汐时刻
第二章 灯塔下的信
```

也支持 `第1章`、`第三回`、`序章`、`楔子`、`尾声`、`Chapter 1`。标题前少于 80 字的书名 / 作者信息不会单独成章；没有命中标题时，按约 2400 字自动切分。

## 数据

- 书籍内容：IndexedDB `work-reader` / `books`
- 阅读进度、书签、显示设置：localStorage（`work-reader:*`）
- 示例书籍是原创演示文本，首次启动自动写入；可在“书库 → 载入示例书籍”恢复。

## 技术栈

React 19 + TypeScript + Vite，纯 CSS 设计令牌，无 UI 框架。图标使用 lucide-react。
